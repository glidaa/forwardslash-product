# Design reference library

UI inspiration for **forwardslash.ch** (repo `email-manager`), collected for design work.

## How to use

1. Read [`features.md`](features.md) for the full feature map.
2. Open a feature folder (e.g. `inbox/`) for Mobbin flows, screens, and notes.
3. Prefer **flows** (closest to product videos on Mobbin) over single screens.
4. Primary comps: Intercom (inbox), Outreach-class tools (Apollo / HubSpot / Juicebox sequences), plus Close / Attio / Cal.com where relevant.
