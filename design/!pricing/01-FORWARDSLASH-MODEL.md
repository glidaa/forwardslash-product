## 3. Enterprise — $5k–$20k / year (get this band right)

Not a seat multiplier alone. Not managed outbound. It’s **platform + commercial terms** for orgs that can’t buy self-serve.

### Band logic (bootstrap-friendly)

| Band | Annual contract | Fits when | Typical shape |
|---|---:|---|---|
| **E1 — Entry enterprise** | **$5,000 / yr** | Small company / one team; invoice, DPA, basic SSO | Capacity for ~5–8 Scale-class users + email support |
| **E2 — Mid** | **$10,000 / yr** | Multi-team, higher volume, admin, priority support | 10–20 operators + higher allowances |
| **E3 — Full** | **$15,000 – $20,000 / yr** | Residency / BYODB / legal / multi-workspace / training | Custom limits, onboarding, SLA, security pack |

**Quote rule:**  
`max( published Scale_or_Growth × seats × 12 × 0.85, band floor )` then snap to **5 / 10 / 15 / 20**.  
Never quote below **$5k/yr** once enterprise scope (procurement, DPA, SSO) is on the table.

### In Enterprise vs Scale self-serve

| | E1 $5k | E2 $10k | E3 $15–20k |
|---|---|---|---|
| Scale product capabilities | ✓ | ✓ | ✓ |
| Annual invoice / PO | ✓ | ✓ | ✓ |
| DPA + security questionnaire | ✓ | ✓ | ✓ |
| SSO | ✓ | ✓ | ✓ + SAML/SCIM path |
| Higher send / AI / storage | modest | clear bump | custom |
| Priority support | email+ | Slack/email | SLA |
| Onboarding / migration | light | included | white-glove |
| Residency / BYODB | — | add-on | in-band or add-on |
| Multi-workspace | — | optional | yes |

### Not included

- You running their campaigns  
- Unlimited services hours (sell migration/training as a **separate** $1.5–5k PS line)
