## Thesis

**No signup.** One job finished in about ten minutes **is** the free membership.

Not a feature tour. Not “ads on, uploads off” as the whole story. They do one real job, keep the artifact, and stay because the work is already theirs.

**Hero hang line:** Start free. Do one job.

**Pay wall (honest):** link-share stays free; pay for email-send polish and serious file uploads. Stickers → `design/!pricing`. No $ in this doc.

---

## Doors

Each door: **job → first artifact → why they stay.**

### 1. Load a list → email + call from their phone

| | |
|--|--|
| **Job** | Get a short list into the workspace and reach people from *their* channels. |
| **First artifact** | A live list + first sends and/or dials from their mailbox and phone. |
| **Why they stay** | The list is already tidy and owned — endowment. Own-channel proof in one sitting. |

*~10 min path:* upload modest list → pick ten rows → send or dial from their number.

### 2. Build a calendar / booking page

| | |
|--|--|
| **Job** | Stand up a public booking page without an admin project. |
| **First artifact** | A shareable booking page (link). |
| **Why they stay** | Something they made — endowment. Colleagues can use the link; no signup required to start. |

*~10 min path:* name the page → set slots → copy link.

### 3. Put an event on → email people on signup

| | |
|--|--|
| **Job** | Run a small event list and follow people who sign up. |
| **First artifact** | Event + signup list; first confirmation / follow-up path. |
| **Why they stay** | Event context lives with the contacts — not a spreadsheet left behind. |

*~10 min path:* create event → open signup → first signup lands on the list.

### 4. Calendar booking that emails

| | |
|--|--|
| **Job** | Booking that notifies — calendar plus email as one seam. |
| **First artifact** | A booked slot that triggered an email. |
| **Why they stay** | First touch → booked meeting made concrete. Pay later for polish (from-domain / ads off), not to prove the loop. |

*~10 min path:* booking page live → test book → email fires (Free may carry ads until pay).

### 5. Try a phone bot on one number

| | |
|--|--|
| **Job** | Hear outbound/inbound assist on a single number before buying seats. |
| **First artifact** | One number live with a simple bot path (or test call logged). |
| **Why they stay** | Dial seam proven on *their* number — own-channel, not a demo farm. |

*~10 min path:* attach one number → run one scripted attempt → review the log.

### 6. Track investors / clients (list + tasks)

| | |
|--|--|
| **Job** | Keep a short investor or client book with next actions — no CRM theatre. |
| **First artifact** | Named list + a few tasks tied to people. |
| **Why they stay** | Quiet system for the relationships that matter; link-share to a partner without a seat tax story. |

*~10 min path:* create list → add 5–10 names → three tasks → share link if needed.

## Shared rules (all doors)

| Keep free | Pay for |
|-----------|---------|
| No signup for core craft (tasks, page, name search, modest list) | Email-send polish (professional identity / ads off / from-domain send) |
| Link-share of list or page | Serious / repeat file uploads beyond free list endowment |
| One job → one artifact in ~10 min | Sequences, dialler depth, team seats (Essentials / Growth / Scale) |

**Bootstrap-real:** Free doors are organic / product-led. Do not buy traffic for Free. Activation before discount.

**CTA grammar:** *Start free* · *Talk to us* (when they need seats / sequences now).
