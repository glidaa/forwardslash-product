Product · catalog vs journey

Feature review.

Every Catalyst catalog capability tagged against the First campaign rail: connect mailbox → get people → write/send from own mailbox → see reply/test in Inbox. Source: design/!pricing/08-FEATURE-CATALOG.md. Journey: First campaign. Conservative: First campaign only when the capability clearly sits on that rail.

Tags

How to read the tags

First campaign

Needed on the first-email path screens (mailbox, people, write/send, inbox, Path C agent prep).

Next journey

Soon after the first send — polish, compliance, tracking, book hygiene, reply assist.

Later

Not for early journeys (voice, sequences volume, pages doors, team/admin, delivery).

Pricing only

Plan or usage framing — not a product screen on the journey.
