1 · Events

Events

Start on page: Event outreach H1. Primary Start free → create Event / Booking page (branded Free). Secondary Talk to us.

First screen after start: Event page (or Booking link) empty — title, date, signup. Side path: upload attendee CSV into a list on the event.

Features that help: Event page · Booking links · Public page · Forms on pages · Lists · CSV upload · Contact book · Own-mailbox send · Templates · Reminders · Timezone care · Campaigns (attendee follow-up) · Calendar sync (later).

Out of first path: Round robin · Power dialler · Sequences volume.

2 · Marketing

Marketing

Start on page: Outbound book for campaigns + pages. Start free → New campaign (or Pages). Talk to us for team.

Features that help: Campaigns · Own-mailbox send · Gmail / Outlook sync · Lists · CSV upload · Templates · Public page · Page blocks · Contact book · Activity timeline · Open & click (later soft) · Shared inbox (Essentials).

4 · Finding leads

Finding leads

6 · B2B calling

B2B calling

Team of callers
