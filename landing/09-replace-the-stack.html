Questions

Before replacing anything.

Does forwardslash.ch need to replace every tool?

No. It can begin as a bounded campaign, contact, follow-up or delivery system and coexist through export, API and explicit ownership.

How should we compare total cost?

Include licences, provider usage, implementation, duplicate administration, manual reporting and the cost of lost context—not subscriptions alone.

Is migration included in A$249?

Self-service imports and export are part of the product direction. Complex mapping, cleansing, integration and managed change would be scoped separately.

What if the pilot fails?

Export the bounded records and activity. A pilot should create evidence, not lock-in.
